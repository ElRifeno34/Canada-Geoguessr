# Canada GeoGuessr (web)

Web front end for the Canada GeoGuessr game, designed with Lovable
(project: https://lovable.dev/projects/7d3267cc-f792-4e42-b755-4ec3661c33e2).

```bash
npm install
npm run dev
npm test
```

City data, hints and facts live in `src/lib/cities.ts`; the map outline is `public/data/canada.geojson`.
