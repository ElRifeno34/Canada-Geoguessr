# Canada GeoGuessr 🍁

A map quiz about Canadian cities. Type the name of a city: if it is one of the 18 cities in the game, it gets pinned on the map of Canada and you learn a fun fact about it. Wrong or repeated guesses cost a life. Find them all before you run out of lives.

Built with React 19, TanStack Start, Tailwind CSS 4 and d3-geo. The app lives in [`web/`](web/).

## How to play

- Type a city name and press **Enter** (or click **Guess**).
- Capital letters, extra spaces and accents don't matter: `quebec city`, `Québec City` and `Quebec` all work.
- A correct guess pins the city on the map and adds a fun fact to the **Discovered cities** panel.
- A wrong guess, or a city you already found, costs one of your **5 lives**.
- Stuck? **Hint** gives you a clue about a random city you haven't found yet.
- Find all **18 cities** to win. The game-over screen shows the cities you missed in grey.

The cities are: Toronto, Montreal, Vancouver, Calgary, Ottawa, Québec City, Victoria, Edmonton, Winnipeg, Regina, Saskatoon, Halifax, Fredericton, Gaspé, Yellowknife, Whitehorse, Iqaluit and Kuujjuaq.

## Features

- Real map of Canada (provinces and territories) drawn from GeoJSON, with zoom and pan
- Animated markers, fun-fact cards, maple-leaf lives and a progress bar
- Start, win and game-over screens
- Light and dark mode (follows your system setting)
- Responsive: on phones the discovered-cities panel becomes a bottom drawer

## Getting started

Requirements: [Node.js](https://nodejs.org/) 22 or later (npm comes with it).

```bash
cd web
npm install
npm run dev
```

Then open http://localhost:8080.

## Code layout

```
web/
├── public/data/canada.geojson   Province and territory outlines used to draw the map
└── src/
    ├── lib/cities.ts            The 18 cities: coordinates, hints, facts, aliases, label placement
    ├── components/CanadaMap.tsx Map rendering (d3-geo projection), markers, labels, zoom
    ├── components/MapleLeaf.tsx Maple-leaf icon used for lives and decoration
    ├── routes/index.tsx         The game: input, lives, hints, side panel, start/win/game-over screens
    ├── routes/__root.tsx        HTML shell, fonts, dark mode, toast notifications
    ├── styles.css               Theme colours (light and dark) and animations
    └── test/                    Unit tests
```

`routeTree.gen.ts` is generated by TanStack Router; don't edit it by hand.

## Adding a city

Add an entry to `CITIES` in [`web/src/lib/cities.ts`](web/src/lib/cities.ts) with its name, latitude, longitude, a hint (which must not contain the city's name) and a fact. If its label overlaps a neighbour on the map, give it a `label` placement (`top`, `bottom`, `left` or `right`, plus an optional offset). Update the city count in `web/src/test/cities.test.ts`, then run `npm test`.

## Deploying

`npm run build` produces a server build for Cloudflare Workers in `web/.output/`; `npx nitro deploy --prebuilt` deploys it. The app was designed in [Lovable](https://lovable.dev/projects/7d3267cc-f792-4e42-b755-4ec3661c33e2), which can also publish it. Changes made in Lovable are not synced to this repo automatically.
